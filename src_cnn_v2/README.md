# CNN-LSTM Airflow Rate Prediction (V2 Pipeline)

This project predicts quantitative airflow leakage rates (L/min) from thermal infrared video sequences. This document describes the V2 "Replica" Workflow, designed to mathematically replicate and benchmark against existing state-of-the-art results.

The pipeline uses a bottom-up approach:

Detection: Locates leaks using temporal-spatial signal processing (with Anchor enforcement).
Extraction: Extracts RAW temperature crops (no pre-normalization).
Modeling: Trains a CNN-LSTM regressor using Asymmetric Loss.

## End-to-End Workflow

### Step 1: Initial Configuration

Configure src_cnn_v2/config_v2.py:

Set EXPERIMENT_NAME. Note: The code now supports reading this from the Target_Experiment environment variable for Slurm jobs.
Set DATASET_CONFIGS to point to your raw data folders.
Set MAX_FLOW_RATE appropriately for your material (e.g., 2.0 for Hardyboard to provide headroom).

Generate Ground Truth:
Run:

```
python scripts/create_ground_truth_labels.py
```

This creates airflow_ground_truth_*.csv in the root directory.

### Step 2: Leak Detection (Anchor-Based)

This step finds the leak coordinates. For challenging datasets (like Hardyboard), we use Positional Anchors to prevent "Hole Swapping" and ensure consistent labeling.

Edit Anchors: Update POSITIONAL_ANCHORS inside src_cnn_v2/find_leaking_holes.py with the (row, col) coordinates of Hole 1 and Hole 2 for your dataset.

Run Detection:

```
python -m src_cnn_v2.find_leaking_holes \
  --dataset_dir /path/to/raw/datasets \
  --base_output_dir Output_SAM/datasets \
  --debug
```

Output: Generates _coordinates.json files for every video.

### Step 3: Dataset Generation (The "Replica" Pipeline)

We generate a dataset containing RAW temperature values. Normalization is handled dynamically during training.

Create Master Metadata:

```
python -m src_cnn_v2.create_metadata_v2
```

Split Data (Maksym Logic):

```
python -m src_cnn_v2.split_data_maksym
```

Create .npy Files:

```
python -m src_cnn_v2.create_cnn_dataset_v2
```

Verify Dataset (Optional but Recommended):

```
python src_cnn_v2/compare_datasets.py \
  --user_dir CNN_dataset/<exp_name>/dataset_... \
  --colleague_dir /path/to/reference/data \
  --all
```

### Step 4: Hyperparameter Tuning (Slurm)

Modify run_hp_search.sh:

```
export Target_Experiment="hardyboard_all_dataset_v2"
python src_cnn_v2/hyperparam_search_v2.py
```

Run:

```
sbatch run_hp_search.sh
```

Result: Updates hyperparam_search.db. Use the best params found to update config_v2.py.

### Step 5: Ensemble Training

Run the following commands:

```
python -m src_cnn_v2.train_v2 --seed 42
python -m src_cnn_v2.train_v2 --seed 43
python -m src_cnn_v2.train_v2 --seed 44
```

Output folders:
Output_CNN-LSTM/.../iter-X_SEED_42
Output_CNN-LSTM/.../iter-X_SEED_43

### Step 6: Evaluation

Run:

```
python -m src_cnn_v2.predict_v2 --seed 42
```

Output: test_set_report.xlsx in the respective result folder.
